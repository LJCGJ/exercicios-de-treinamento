# Contribuindo

Obrigado por considerar contribuir com este projeto.

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch para sua alteração.
3. Implemente a funcionalidade ou correção.
4. Adicione ou atualize testes quando necessário.
5. Execute a suíte de testes localmente.
6. Abra um pull request com uma descrição clara.

## Regras

- mantenha o projeto simples e didático
- priorize testes e comportamento observável
- mantenha a documentação coerente com o código
- evite mudanças sem necessidade

## Validação local

```powershell
python -m pytest -q
```
