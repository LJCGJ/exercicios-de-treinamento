# Testes da API

## Objetivo
Garantir que cada operação do CRUD do catálogo de produtos funcione conforme o esperado.

## Cobertura mínima
- criação de produto
- listagem de produtos
- consulta por ID
- atualização de produto
- remoção de produto

## Estratégia
Usar o cliente de testes do FastAPI para simular requisições HTTP e verificar status, payload e comportamento em casos de sucesso e erro.
