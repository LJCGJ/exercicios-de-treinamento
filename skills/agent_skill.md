# Skill: Agent Orchestration

## Função
A skill define como o agente orquestra a lógica de subagentes e organiza a execução do fluxo.

## Quando usar
- quando houver necessidade de dividir tarefas entre agentes;
- quando um processo precisa ser coordenado por etapas;
- quando a resposta final depende de múltiplos módulos.

## Regras
- manter a sequência lógica de execução;
- delegar tarefas para agentes específicos;
- consolidar os resultados em uma resposta final;
- salvar evidências de execução em arquivo ou log.

## Resultado
Uma resposta final clara, objetiva e compatível com a necessidade do usuário.
